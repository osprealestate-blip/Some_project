# T1.4 Matching test (go/no-go)

**Goal:** find out how well DLD building names link to real buildings, before building M2 on it.

**Depends on:** T1.2, T1.3.

**Read first:** `CLAUDE.md`, `docs/datasets.md` (Linking keys), `db/migrations/0001_init.sql`
(buildings, land_plots, match_reviews).

## Steps
1. Take the 100 most-traded `raw_building` values in Dubai Marina (community code 392).
2. For each, try in order and record which worked:
   a. land number -> `land_plots` -> footprint. T1.1 found land numbers but NO coordinates in any DLD file, so
      first look for a footprint source (OSM, or the Dubai Pulse `dsc_buildings` dataset) and say what it holds.
   b. name match against OSM building names inside the community polygon (pg_trgm similarity)
   c. no match
3. Write a report `docs/matching-test.md`: share matched by each method, 10 examples of failures, and
   a recommendation for M2 (which method to build on, how much hand-placing is needed).

## Checks
- The report exists with numbers, not estimates.
